# Streamlit components and extras

streamlit-extras is a collection of Python modules that extend Streamlit. Some extras are custom Streamlit components with a frontend; others are Python functions, layout helpers, or utilities. The library itself is not a single component.

## What is a Streamlit component?

A custom component connects a Python API to a frontend so an app can display interactive UI beyond Streamlit's built-in elements. It is one way to build an extra, not a requirement for every extra.

Browse the [extras catalog](extras/index.md) to see the available modules and their examples. To build a custom component, see Streamlit's [components gallery](https://streamlit.io/components) and [component tutorial](https://blog.streamlit.io/how-to-build-your-own-streamlit-component/). If you want to contribute an extra, start with the [contribution guide](contributing.md).

Browse extras

Find a focused addition for your Streamlit app in the full list below, or use the search bar to look up a feature by name. Each reference page includes its import path, function documentation, and example code.

A few places to start:

  • Toggle button to reveal a short piece of content.
  • Dataframe explorer to add filtering controls to a dataframe.
  • Chart container to explore the data behind a chart.

Want to contribute a new entry? See Contributing.

All extras (51)

  • 👤 Avatar: Display a circular avatar image with optional label and caption.
  • 🏷️ Badges: Create custom badges (e.g. PyPI, Streamlit Cloud, GitHub, Twitter, Buy Me a Coffee)
  • ⬇️ Bottom Container: A multi-element container that sticks to the bottom of the app.
  • ☕ Buy Me a Coffee Button: Adds a floating button which links to your Buy Me a Coffee page
  • 🥅 Capture: Capture utility extensions for the standard streamlit library
  • 🃏 Card Selector: Card-based option picker with icons, titles, and descriptions — like st.segmented_control but bigger.
  • ⬇ Chart annotations: Add annotations to specific timestamps in your time series in Altair!
  • 🖼️ Chart container: Embed your chart in a nice tabs container to let viewers explore and export its underlying data.
  • 📊 Chart.js Chart: Display charts using the Chart.js library with Streamlit theme integration.
  • 🚦 Concurrency limiter : This decorator limit function execution concurrency with max_concurrency param.
  • 🍪 Cookie Manager: Read and write browser cookies from Python using a dict-like interface.
  • 🏃‍♂️ Customize running: Customize the running widget
  • 🔭 Dataframe explorer UI: Let your viewers explore dataframes themselves! Learn more about it on this blog post
  • 📐 Diagrams: Render mingrammer/diagrams architecture diagrams in Streamlit, plus a built-in Streamlit node.
  • 🌲 Directory Tree: Collapsible directory tree with Material icons and optional click-to-select.
  • 🆒 Echo Expander: Execute code, and show the code that was executed, but in an expander.
  • 🌐 Eval JavaScript: Evaluate JavaScript expressions in the browser and return results to Python.
  • 🛡️ Exception Handler: Override Streamlit's uncaught exception handler to customize error display and logging.
  • 🔘 Floating button: A button that stays fixed at the bottom right corner of the screen. Perfect for creating action buttons that are always accessible to users, such as chat interfaces.
  • 👩‍🚀 Function explorer: Give a UI to any Python function! Very alpha though
  • 🧮 Great Tables: Render Great Tables objects in Streamlit. Great Tables allows you to create wonderful-looking display tables in Python. The table automatically adapts to Streamlit's theme (light/dark) and updates live when the user switches themes.
  • 💠 Grid Layout: A multi-element container that places elements on a specified grid layout.
  • 🔀 Image Compare Slider: Compare two images with an interactive slider overlay.
  • ✂️ Image Crop: Interactive image cropping with adjustable bounds.
  • 🤠 Image Selector: Allows users to select an area within an image, using a lasso or a bounding box.
  • 📝 JSON Editor: An interactive JSON viewer/editor component built with React and CCv2.
  • 💡 Jupyterlite: Add a Jupyterlite sandbox to your Streamlit app in one command
  • ⌨️ Keyboard text: Create a keyboard styled text
  • 🎯 Keyboard to URL: Create bindings so that hitting a key on your keyboard opens an URL in a new tab!
  • 🌧️ Let emojis rain: Use this to create more animations like st.balloons() and st.snow()
  • 💾 Local Storage Manager: Read and write browser localStorage from Python with automatic JSON serialization.
  • 📅 Mandatory Date Range Picker: Just like st.date_input, but enforces that it always and only returns a start and end date, even if the user has only selected one of the dates. Until the user selects both dates, the app will not run.
  • 🫵 Mentions: Create nice links with icons, like Notion mentions! **Note: There's also a great st.link_button in the native Streamlit commands offering! Have a look at it!
  • ♠️ Metric Cards: Restyle metrics as cards with custom styles. Note: you can now also use the native st.container(border=True) to make nice cards with a border.
  • 📄 Pagination: A pagination widget for navigating through pages of content with numbered page buttons, prev/next arrows, and intelligent truncation.
  • 🎯 Radial Menu: A circular menu component that displays options in a ring around a central button.
  • ⭐ Read-only Star Rating Component: A read-only Star rating component for Streamlit.
  • 🔀 Redirect: Programmatically redirect users to external or internal URLs.
  • ↔️ Resizable Columns: Drag-to-resize columns, a drop-in replacement for st.columns with interactive dividers.
  • 📜 Scroll to Element: Programmatically scroll to any element by its key.
  • 🕸️ Sigma Graph: Interactive network graph visualization using sigma.js with WebGL rendering, supporting NetworkX graphs and node-link dictionaries.
  • 🦴 Skeleton Placeholder: A single-element container which displays a skeleton placeholder.
  • ✏️ Specialized Inputs: Polished, specialized text inputs — phone, email, URL, money, search, password — built on st.components.v2. Pixel-perfect native Streamlit styling.
  • 🔛 Stateful Button: Button that keeps track of its state, so that it works as a toggle button
  • 💬 Stateful Chat: A chat container that automatically keeps track of the chat history.
  • 🪜 Steps: Progress-steps indicator for multi-step workflows, with vertical/horizontal orientation and numbered or dotted styles.
  • 📦 Stlite Sandbox: Execute untrusted Streamlit code in a sandboxed environment.
  • 🎮 Three.js 3D Viewer: Display 3D models (GLTF, GLB, OBJ, STL, PLY, FBX) with interactive orbit controls using Three.js.
  • ✔️ To-do items: Simple Python function to create to-do items in Streamlit!
  • ➡️ Toggle button: Toggle button just like in Notion!
  • ❗ Word importances: Highlight words based on their importances. Inspired from captum library.
